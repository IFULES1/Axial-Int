# Snapshot — 2026-08-10 (P5 Billing + Reports)

## Objectif
Implémenter P5 : crédits (trial/free/purchased) + coûts par type + consommation
atomique + Stripe ; persistance rapports + export PDF (ReportLab).

## Tâches complétées (P5)
### Billing (`app/modules/billing/`)
- `catalog.py` : CREDIT_COSTS (etude_marche 40, analyse_concurrentielle/veille/risques 25,
  synthese_executive 25, analyse_approfondie 60, agent_message 2) + aliases legacy
  (market_study→etude_marche, competition→analyse_concurrentielle, tech_watch, risk_analysis),
  `cost_for()` (défaut 25). PLANS = 5 tiers (free_beta 120cr/14j, solo_founder 79$/250,
  startup_pro 129$/700/2 sièges, enterprise, early_backer).
- `models.py` : `CreditBalance` (user_id PK, trial/free/purchased_credits, trial_expires_at).
- `service.py` : get_or_create_balance (init Free Beta 120cr/14j), available_credits (trial expiré=0),
  check_credits, **consume_credits ATOMIQUE (SELECT FOR UPDATE, ordre trial→free→purchased, admin bypass,
  402 si insuffisant)**, grant_purchased.
- `stripe_gateway.py` : CREDIT_PACKS (starter 50/30€, pro 100/55€, scale 200/100€), create_checkout_session,
  parse_webhook (vérif signature, grant sur checkout.session.completed). **503 propre si Stripe non configuré**.
- `router.py` : GET /billing/plans (public), /balance, /check, POST /checkout, /webhook.
### Reports (`app/modules/reports/`)
- `models.py` : `Report` (id, user_id, analysis_type, title, content markdown, sources JSONB).
- `pdf.py` : `render_pdf(title, markdown)` via ReportLab (headings #/##/###, **gras**, bullets) → bytes A4.
- `service.py` : create/list/get/delete + export_pdf.
- `router.py` : POST /reports, GET /reports, GET /reports/{id}, GET /reports/{id}/pdf, DELETE /reports/{id}.
### Migration
- `0003_billing_reports.py` (credit_balances + reports). Chaîne : base→0001→0002→**0003 (head)**. `alembic heads` = 1 seul.
- env.py importe billing + reports models.
- main.py monte billing + reports routers.
- Deps ajoutées : `stripe>=11`, `reportlab>=4.2`.
