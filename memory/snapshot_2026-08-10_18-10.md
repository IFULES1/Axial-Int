# Snapshot — 2026-08-10 (P1 Auth + Analytics)

## Objectif
Implémenter P1 du rebuild Axial Intelligence : auth `POST /auth/register {email,password}` (UUID, freemail + onboarding conservés) + module analytics (suivi users/KPI) prêt à appliquer.

## Tâches complétées (P1)
- [✓] **Module auth** dans `app/modules/auth/` :
  - `freemail.py` : `is_professional_email()` + FREEMAIL_DOMAINS (porté verbatim de insight-map).
  - `schemas.py` : RegisterRequest/LoginRequest/AuthUser/TokenResponse — **identité UUID only**.
  - `security.py` : `decode_token()` (JWT HS256 Supabase, vérif locale), `get_current_user`/`get_current_admin` deps, résolution is_admin depuis metadata.
  - `supabase_client.py` : clients public (anon) + admin (service_role), lazy.
  - `service.py` : `register()` (invitation policy → freemail policy → create_user admin API email_confirm → sign_in → analytics.record_signup → tokens) + `login()`.
  - `router.py` : POST /auth/register, POST /auth/login, GET /auth/me.
- [✓] **Module analytics** dans `app/modules/analytics/` :
  - `client.py` : fire-and-forget, **no-op si ANALYTICS_DATABASE_URL vide**. Fns : record_signup/record_login/record_event/increment_usage. Écrit dans base séparée.
  - `schema.sql` : tables `analytics.user_profiles` (first_seen_at, last_seen_at, quota infos), `usage_counters` (par période YYYY-MM), `events` (JSONB extensible KPI) + **RLS** (admin_read via jwt is_admin, writes service_role). Idempotent.
- [✓] `scripts/seed_users.py` (+ `make seed-users n=N`) : crée N comptes test emails pro.
- [✓] Tests : `tests/test_auth.py` (freemail, decode JWT, extraction identité, token expiré). **6 passed**, ruff clean.
- [✓] `email-validator` ajouté aux deps (EmailStr).
