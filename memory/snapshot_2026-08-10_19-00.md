# Snapshot — 2026-08-10 (P3 Analysis + llm_client)

## Objectif
Implémenter P3 : le cœur "faire tourner l'algo" — point d'entrée unique `run_analysis`,
provider LLM abstrait (`llm_client`), dégradation propre, streaming SSE, templates portés.

## Tâches complétées (P3)
- [✓] **`app/shared/llm_client/`** (provider-agnostique) :
  - `base.py` : Protocols `WebSearchProvider` / `EnrichProvider`, dataclass `LLMResult`, `ProviderUnavailable`.
  - `perplexity.py` : `PerplexityProvider` (OpenAI SDK vs api.perplexity.ai, model sonar-pro par défaut, available()/generate()).
  - `claude.py` : `ClaudeProvider` (enrichissement, gate claude_enrichment_enabled + clé, available()/enrich()).
  - `__init__.py` : `web_search_provider()`, `enrich_provider()`, `providers_health()`.
- [✓] **`app/modules/analysis/`** :
  - `prompts.py` : 5 templates portés VERBATIM de insight-map (synthese_executive, analyse_concurrentielle, veille_technologique, analyse_risques, etude_marche) + SOURCES_INSTRUCTION + SYSTEM_PROMPT + ENRICH_SYSTEM_PROMPT + ANALYSIS_LABELS + get_prompt_template/is_valid_type.
  - `schemas.py` : AnalysisRequest/AnalysisResponse + available_types().
  - `service.py` : **`run_analysis()` point d'entrée unique** — RAG best-effort → prompt → web-search → enrich optionnel. **Dégradation propre** : si web-search indispo/échoue → AnalysisResult(degraded=True, status_note, message clair), JAMAIS de crash. `stream_analysis()` = générateur SSE (events progress/step/done, gère degraded). `_sse()` format `data: {...}\n\n`.
  - `router.py` : GET /analysis/types (public), POST /analysis/run (sync), POST /analysis/stream (SSE). run/stream protégés par auth.
- [✓] main.py monte le routeur analysis.
- [✓] Tests `tests/test_analysis.py` : templates ont {context}, type inconnu → 400, **dégradation sans crash** (monkeypatch provider indispo), fallback template, routes montées/protégées. **15 passed total**, ruff clean.
