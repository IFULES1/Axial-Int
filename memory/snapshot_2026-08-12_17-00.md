## Bugs rencontrés & résolus pendant la revue
1. **CORS** : front sur 3005, backend autorisait 3000 → ajouté 3005 à ALLOWED_ORIGINS.
2. **Conflit de port majeur** : **Docker tourne** et publie l'ANCIEN stack insight-map sur 8080 (routes /api/memory/*) ET 3000. Le navigateur (IPv6 ::1) tombait sur l'ancien backend Docker → PUT /memory/profile 404.
   → **Résolu** : mon backend déplacé sur **127.0.0.1:8090**, front repointé `NEXT_PUBLIC_API_URL=http://127.0.0.1:8090`. Ancien stack Docker laissé intact.
3. **Boucle onboarding** : `/auth/me` lisait onboarding_complete depuis le **JWT** (figé à false à l'inscription) → après création profil, toujours false → /workspace rebouclait sur /onboarding.
   → **Résolu** : `/auth/me` rend onboarding_complete **autoritatif depuis la DB** (memory.onboarding_complete). Backend relancé avec --reload.
