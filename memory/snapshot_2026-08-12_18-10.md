Le prototype exact est maintenant un **vrai build Next.js compilé** (plus de Babel-in-browser),

### Comment
- **CSS** : 3 blocs <style> (~82K) → `frontend/app/globals.css` verbatim. Fonts url("UUID") réécrites → `/proto/fonts/UUID.woff2`. Retiré le placeholder `{__TWEAKS_STYLE}` (injection runtime, invalide en CSS statique).
- **JS** : tous les scripts inline (data.js/surfaces-data.js/theme.js/i18n.js) + les 12 modules .jsx (atoms, landing, auth, onboarding, shell, conversations, surfaces-*, tweaks, app) concaténés → `frontend/app/_prototype/App.jsx` (un seul module client).
  - Préfixé `"use client"` + `import React from "react"` + stub `ReactDOM` no-op (neutralise le mount createRoot).
  - **Fix clé** : `const {…} = React` répété dans chaque script → collision en module unique. Converti en **`var {…} = React`** (9 occurrences) — redéclaration autorisée, alias préservés.
  - Suffixé `export default App;`.
- **Montage** : `app/page.tsx` = `dynamic(() => import("./_prototype/App"), { ssr:false })` (client-only, évite window/localStorage au SSR). `app/layout.tsx` minimal.
- **Nettoyage** : mes anciennes pages Tailwind (auth, onboarding, (app)) archivées dans `frontend/_reconstruction_backup/`. app/ = {_prototype/App.jsx, globals.css, layout.tsx, page.tsx}.
- Fonts servies depuis `frontend/public/proto/fonts/`.
