# Sources v2 — plan d'implémentation

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task.

**Goal:** brancher les sources décidées le 14/09 : contraintes de recherche, cascade à niveaux avec Perplexity, Pappers, base investisseurs en conversation, base de connaissance admin, Drive comme source, sources par type de rapport, santé réelle des fournisseurs.

**Architecture:** tout passe par les points d'extension existants : `app/shared/search/*` (fournisseurs, orchestrateur, rerank), `grounding.assemble`, `ANALYSIS_DIRECTIVES`, `rag/vector_store` (collection `knowledge_base`), `integrations/service` (jeton Google). Nouveau module `app/modules/kb/` et `app/shared/enrich/pappers.py`.

**Tech Stack:** FastAPI, SQLAlchemy, Alembic (head `0023_rapports_v2` → `0024_sources_v2`), httpx, Qdrant, Cohere, Next.js 14 (`frontend/app/_prototype/App.jsx`, `bridge.js`).

**Spec:** `docs/superpowers/specs/2026-09-14-sources-v2.md`

## Global Constraints

- Aucune clé absente ne produit d'erreur visible : fournisseur ignoré, bouton masqué.
- Jamais d'exception hors d'un adaptateur fournisseur : `[]`/`None` + `logger.warning` + `notifier_fournisseur(..., bascule=True)`.
- Les prompts de rapport (`ANALYSIS_DIRECTIVES` hors champ `sources`, `PROMPT_*`) ne changent pas d'un octet.
- Registre : l'app vouvoie ; textes FR et EN dans les deux dictionnaires i18n.
- Tests : `PYTHONPATH=. .venv/bin/pytest tests -q` vert ; `npm --prefix frontend test` vert. Jamais `npm run build` pendant `next dev`.
- Secrets : jamais de valeur dans le code, les tests, les journaux (`_sans_secret`).
- Un commit par tâche, message en français.
